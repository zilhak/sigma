# `font_not_default`

| | |
|---|---|
| 기본 | **OFF** (opt-in) |
| 스코프 | TEXT |
| 추가 왕복 | 문서 노드 `fonts.default` 조회 |
| 자동수정 | 없음 |

## 무엇을 잡나

이 파일이 정한 기본 폰트와 **다른 폰트를 쓰는 TEXT**.

## 왜 필요한가

**파일 기본 폰트는 새로 만들 때만 적용된다.** 설정 이전에 만든 텍스트는 그대로 남는다.
스펙 마스터는 재등록하면 바뀌지만, **화면에 직접 그린 raw TEXT는 옛 폰트가 그대로 남는다.**

그걸 찾는 일이 지금까지 사람이 섹션마다 훑는 것이었다 — `scope:"file"` 한 번이면 된다.

## 파라미터

| 이름 | 기본값 | 설명 |
|---|---|---|
| `family` | (문서 `fonts.default`) | 기대 패밀리. 지정하면 문서 설정을 override |
| `allow` | — | 함께 허용할 패밀리 (예: 코드용 고정폭) |
| `flagMixed` | **true** | 한 텍스트 안에 폰트가 섞인 경우(`figma.mixed`)도 잡을지 |

## 기준이 없으면 판정하지 않는다

기대 패밀리는 문서 노드의 `fonts.default`에서 읽는다. **설정이 없으면 이 룰은 아무것도 하지 않는다** —
기준 없이 전부 위반으로 만들지 않기 위해서다.

```jsonc
sigma_set_page_data({ token, pageId: "document", key: "fonts", value: '{"default":"Pretendard"}' })
```

## 오탐과 의도적 스코프 축소

- 코드 블록·숫자 표처럼 다른 폰트가 정당한 경우가 있다 — `allow`에 넣거나 노드별로 면제한다.
- `flagMixed`는 한 텍스트 안에 여러 폰트가 섞인 상태를 잡는다. 부분 강조로 폰트를 바꾸는 운영이면 끈다.

## 면제하는 법

의도한 예외는 [`lint-ignore`](../suppress.md)로 **사유와 함께** 면제한다.

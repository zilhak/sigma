# `outside_section`

| | |
|---|---|
| 기본 | **ON** (opt-out) |
| 스코프 | 페이지 루트 전용 |
| 추가 왕복 | 없음 |
| 자동수정 | 없음 |

## 무엇을 잡나

페이지 직속에 섹션이 아닌 배치 노드(FRAME/COMPONENT/INSTANCE/GROUP)가 놓인 것.

## 왜 필요한가

Figma에서 **캔버스에 항상 보이는 이름은 섹션 라벨뿐이다.** 콘텐츠가 섹션 밖에 있으면 줌아웃했을 때
그게 무엇인지 알 방법이 없다. 계층을 Section → Frame → 콘텐츠로 균일하게 유지하면 나머지 기하
규칙(여백·겹침)도 "섹션 안"이라는 같은 기준으로 판정된다.

[찾기 쉬움](README.md#찾기-쉬움-findability) 세 수단 중 "섹션 라벨"을 담당한다.

## 파라미터

없음. `{ "enabled": false }`로 끄는 것만 가능하다.

## 오탐과 의도적 스코프 축소

- **서브트리 검사에선 실행되지 않는다.** `sigma_lint(nodeId/path)`로 검사하면 그 자식들은 "섹션 밖"이
  아니라 "그 컨테이너 안"이므로, 여기서 이 규칙을 돌리면 정상 자식이 전부 위반이 된다.
- 배치형 노드만 본다 — TEXT 같은 리프는 대상이 아니다.

## 면제하는 법

[`lint-ignore`](../suppress.md)로 노드별 면제. 페이지 전체가 섹션을 안 쓰는 성격이면 page config로 끈다.

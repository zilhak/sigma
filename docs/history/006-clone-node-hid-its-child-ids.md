# 006. clone_node 가 자식 id 를 감춰서 매번 거대한 get_tree 를 다시 부르게 했다

> 관련 코드: `packages/figma-plugin/src/node-ops/move.ts` (`collectClonePairs`, `retargetInternalHyperlinks`)
> 테스트: `packages/figma-plugin/__tests__/clone-child-id-map.test.ts`
> 2026-08-07 실측 · 2026-08-08 수정

## 증상

`sigma_clone_node` 응답은 **복제된 최상위 노드 id 하나**만 줬다. 그런데 Figma 의 `clone()` 은
**자식 전부에 새 id 를 부여**한다. 복제본 내부를 손보려면 그 새 id 들이 필요한데, 알아낼
방법이 `sigma_get_tree` 재조회뿐이었다.

2026-08-07 멤버 관리 섹션 작업 실측 — 상태 프레임 **5개**를 클론하고 각각을 고치려다:

- 원리상 `get_tree` **5회**
- 그중 **두 번이 응답 6.7만 자 / 20.3만 자로 MCP 토큰 한도를 초과**해 파일로 떨어진 뒤
  python 으로 파싱해야 했다
- 정작 필요했던 건 `246:81891 = 1행 프레임` 같은 **id ↔ 이름 몇 줄**이었다

**필요한 건 트리가 아니라 매핑인데 트리를 받는 구조였다.**

### 곁가지 — 하이퍼링크가 원본을 가리킨 채 복제된다

주석 규약상 마커와 범례는 `setRangeHyperlink` 로 서로를 **노드 id 로** 가리킨다. 클론하면
그 링크는 **원본 노드를 계속 가리킨다** — 복제본의 마커를 누르면 원본 섹션으로 튄다.
렌더 결과가 같아서 **육안으로는 절대 발견되지 않는다.** 사용처는 이걸 뒤늦게 알고
"클론 섹션은 링크를 처음부터 다시 배선할 것" 이라고 자기 CLAUDE.md 에 적어 두고 있었다.

## 무엇을 했나

- **`childIdMap`(원본 자식 id → 복제 자식 id)을 기본 포함.** 화면 하나가 90~250 노드,
  한 쌍이 30자 안쪽이라 250개여도 7KB 수준 — `get_tree` 재조회(6.7만~20만 자)보다
  **한 자릿수 이상 싸다.** `includeNames:true` 면 이름·타입까지.
- 상한 2000, 넘으면 **`childIdMapTruncated` 를 명시**한다. 조용히 자르지 않는다
  (`get_tree` 의 `truncated` 를 놓쳐 42건을 0건으로 보고한 전례가 있다 — [[004]] 와 같은 원칙).
- 복제본 안 TEXT 의 `type:'NODE'` 링크가 복제 범위 안을 가리키면
  **`hyperlinks.internalPointingToSource` 로 알린다.** `rewireInternalLinks:true` 면 복제본
  내부로 다시 연결한다. 복제 범위 **밖**을 가리키는 링크는 정상이므로 건드리지 않는다.

## 왜 그렇게 만들었나 (되돌리지 말 것)

- **매핑을 만들려고 내부에서 `get_tree` 를 부르지 않는다.** 복제 직후 원본과 복제본을 둘 다
  손에 쥔 그 시점이 유일하게 공짜다. 내부 호출은 같은 비용을 숨기는 것일 뿐이다.
- **재배선을 기본값으로 켜지 않는다.** "원본을 참조하는 복제본" 이 의도인 경우가 있고,
  되돌리기 어렵다. 다만 **끈 상태에서도 건수는 반드시 알린다** — 지금까지는 침묵이었다.
- 대응은 `clone()` 이 **자식 순서를 보존한다**는 성질에 의존한다(API 가 대응을 안 준다).
  그래서 길이가 어긋나면 그 가지에서 멈춘다.

## 테스트 함정 — 개수만 세면 안 된다

매핑이 **한 칸 밀리면 개수는 그대로 맞는다.** 그럴듯하게 틀리므로 테스트는 대응 값의
**이름·타입까지** 검증하고, 복제본 id 가 원본 id 와 다른지도 본다(항등 매핑이면 무의미하다).

또 브리지는 이제 제네릭 패스스루라 손댈 필요가 없지만, **`code.ts` 의 `case 'clone-node'` 는
여전히 인자를 손으로 나열**한다. 새 옵션을 거기 빠뜨리면 조용히 사라지므로,
`CloneNodeOptions` 의 필드가 전부 그 case 에 나타나는지 `bridge-forwarding.test.ts` 가 지킨다.

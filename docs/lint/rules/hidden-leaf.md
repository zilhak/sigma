# `hidden_leaf`

| | |
|---|---|
| 기본 | **ON** (opt-out) |
| 스코프 | 모든 노드 |
| 추가 왕복 | 없음 |
| 자동수정 | 없음 |

## 무엇을 잡나

`visible: false`인 노드가 트리에 남아 있는 것.

## 왜 필요한가

숨긴 노드는 대개 **지우기 애매해서 눈에서만 치운 것**이다. 화면에 없으니 유지보수 대상에서 빠지는데,
파일에는 남아 용량과 레이어 패널을 차지하고, 나중에 실수로 다시 켜지면 옛 디자인이 튀어나온다.
"지울 것인가 남길 것인가"를 명시적으로 결정하게 만드는 룰이다.

같은 문제의 **암묵적 버전**은 [`fully_occluded_sibling`](fully-occluded-sibling.md)이 잡는다 —
`visible`은 true인데 불투명한 형제에 완전히 덮여 어차피 안 보이는 경우.

## 파라미터

없음. `{ "enabled": false }`로 끄는 것만 가능하다.

## 오탐과 의도적 스코프 축소

- 프로토타입 오버레이처럼 **의도적으로 숨겨 두는 상태 레이어**가 있는 파일에서는 위반이 많이 난다.
  그런 파일은 노드별 면제보다 page config로 끄는 편이 낫다.

## 면제하는 법

[`lint-ignore`](../suppress.md)로 노드별 면제. 상태 레이어라면 reason에 그 사실을 적는다.

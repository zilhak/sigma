# `section_overlap`

| | |
|---|---|
| 기본 | **ON** (opt-out) |
| 스코프 | 형제 SECTION 간 |
| 추가 왕복 | 없음 |
| 자동수정 | 없음 (재배치는 사람 판단) |

## 무엇을 잡나

형제 SECTION끼리 바운딩박스가 겹치는 것.

## 왜 필요한가

섹션이 겹치면 어느 섹션에 속한 콘텐츠인지 시각적으로 구분되지 않고, 섹션 라벨도 서로를 가린다.
`resize`로 섹션을 키우다 옆 섹션을 덮는 일이 흔해서, **변형 후 회귀 검사**로 쓰는 것이 이 룰의
주 용도다.

## 파라미터

없음. `{ "enabled": false }`로 끄는 것만 가능하다.

간격이 부족한 것(겹치지는 않음)은 [`section_gap`](section-gap.md)이 담당한다.

## 오탐과 의도적 스코프 축소

- 형제 관계일 때만 본다. 중첩 섹션(섹션 안 섹션)은 부모-자식이라 대상이 아니다.

## 면제하는 법

[`lint-ignore`](../suppress.md)로 노드별 면제.

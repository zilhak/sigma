# `stray_pixel`

| | |
|---|---|
| 기본 | **ON** (opt-out) |
| 스코프 | 모든 노드 |
| 추가 왕복 | 없음 |
| 자동수정 | 없음 |

## 무엇을 잡나

`x` / `y` / `width` / `height` 중 정수가 아닌 값이 있는 노드.

## 왜 필요한가

소수 좌표는 대부분 **손으로 끈 결과**이지 의도가 아니다. 렌더링에서 경계선이 흐려지고, 개발자가
값을 옮겨 적을 때 반올림 차이가 생긴다. 정수로 맞춰 두면 좌표 계산이 예측 가능해진다.

## 파라미터

없음. `{ "enabled": false }`로 끄는 것만 가능하다.

## 오탐과 의도적 스코프 축소

- **INSTANCE 내부 노드는 기본 제외**된다. 인스턴스 안쪽 좌표는 마스터가 정하는 것이라 그 자리에서
  고칠 수 없고, 마스터 하나가 어긋나면 인스턴스 수만큼 위반이 복제돼 목록이 무의미해진다.
- 회전·오토레이아웃 결과로 소수가 생기는 경우가 있어, 자동수정은 제공하지 않는다(반올림 방향이
  레이아웃을 바꿀 수 있다).

# 009. nodeId 를 사람이 눈으로 읽어 스크립트에 옮겨 적고 있었다

> 관련 코드: `packages/figma-plugin/src/node-ops/tree.ts` (`resolvePaths`),
> `packages/server/src/mcp/handlers/figma.ts` (`sigma_find_node` 의 `paths` 모드)
> 2026-08-07 실측 · 2026-08-08 수정

## 증상

호출자의 빌드 스크립트는 전부 이렇게 시작했다:

```python
PAGE     = "156:1580"
SEC      = "246:79108"      # 클러스터 · 대시보드 섹션
FRAME_A  = "161:47549"      # Ⓐ 채워짐 · 첫 화면
```

이 숫자들은 **직전 호출의 응답에서 사람이 눈으로 읽어 옮겨 적은 값**이다. 결과:

- **세션이 바뀌면 다시 조회**해야 한다. 섹션 하나 만드는 데 스크립트가 3~4개로 쪼개지고
  (`build-*.py` → `fix-*.py` → `link-*.py`) 그 사이를 id 를 손으로 나르며 이었다.
- **중간에 실패하면 재실행이 안 된다.** 앞부분은 이미 적용됐는데 스크립트는 그걸 모른다.
  실제로 `build-clusterdash.py` 가 없는 메서드에서 멈추자 `--step` 인자를 급히 넣고
  `fix-clusterdash-panel.py` 를 따로 써야 했다.
- **사람이 읽어도 무엇인지 모른다.** 리뷰·인수인계가 안 된다.

기존 도구로는 배치가 안 됐다 — `sigma_find_node({path})` 는 한 번에 하나이고 응답도 노드
상세 전체라 id 하나 얻자고 페이로드를 치렀다. `where` 는 조건 검색이라 "이 이름 5개를 각각"
에는 안 맞고, `get_tree` 는 구조를 받아 호출자가 이름으로 뒤지는 왕복이 매번 붙었다.

## 무엇을 했나

`sigma_find_node` 에 **`paths` 배열 모드**를 넣었다. 왕복 1회로 여러 경로를 nodeId 로 해석하고,
응답은 id 해석에 필요한 것만 싣는다(`{path, nodeId, name, type, matches?, error?}` + `resolved`/`failed`).

- **부분 실패 허용** — 하나가 없어도 나머지는 해석된다. 실패한 원소에 `path` 를 되울려
  어느 경로가 실패했는지 응답만으로 알 수 있다.
- **다중 매칭을 조용히 첫 번째로 고르지 않는다.** `matches` 개수를 함께 돌려준다 —
  모른 채 쓰면 "그럴듯하게 틀린 대상" 에 작업하게 된다.

## 왜 새 도구(`sigma_resolve`)를 만들지 않았나

처음 제안은 `sigma_resolve` 라는 **전용 신규 도구**였는데, `docs/tool-conventions.md` 와
두 군데서 충돌했다:

- §1.2 — 이름은 `sigma_<verb>_<noun>` 이고 동사는 **고정 사전**에서만 고른다.
  `resolve` 는 사전에 없고, 게다가 **noun 이 없어** 무엇을 resolve 하는지 이름으로 알 수 없다.
- §3 · §1.4 — *"단일 처리 도구 + batch_* 도구를 쌍으로 만들지 않는다. 같은 도구가 스칼라와
  배열을 모두 받게 한다"*. 전용 배치 도구는 규약이 정확히 금지하는 형태다.

그래서 규약이 정한 형태(**기존 도구가 배열을 받는다**)로 구현했다. 규약을 이기려면 규약을
고치는 것이 먼저이고, 말없이 어기면 다음 사람이 `tool-conventions.md` 를 믿을 수 없게 된다.

남은 모호성 하나는 직접 정했다 — 기존 `path` 의 `string[]` 은 "여러 경로" 가 아니라
**한 경로의 세그먼트 목록**(`["A","B","C"]` = `A/B/C`)이라, 여러 경로를 `path` 에 얹으면
`string[][]` 이 되어 타입이 모호해진다. 그래서 **별도 인자 `paths`** 로 갈랐다.

## 되돌리면 안 되는 이유

**로컬 nodeId 캐시는 답이 아니다.** 문서가 밖에서 바뀌면 캐시는 그걸 모르고, 이 저장소가
여러 커밋에 걸쳐 없애 온 **"조용히 틀린 대상에 쓴다"** 를 되살린다. 캐시 대신
**싸게 다시 묻는** 경로를 만든 것이다. 굳이 캐시를 둔다면 저장 위치는 로컬 파일이 아니라
Figma 파일 자체(`sigma_set_page_data`)여야 하고, 검증 배치가 함께 와야 한다.

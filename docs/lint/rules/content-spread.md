# `content_spread`

| | |
|---|---|
| 기본 | **OFF** (opt-in) |
| 스코프 | **페이지 루트 전용** — 서브트리 검사에선 실행 안 됨 |
| 추가 왕복 | 없음 |
| 자동수정 | 없음 |

## 무엇을 잡나

최상위 노드를 `maxGap` 이내로 이어지는 덩어리로 묶고, **가장 큰 덩어리(본진) 밖에 홀로 떨어진 노드**를
검출한다.

## 왜 필요한가

**"페이지를 열었는데 내용을 못 찾겠다"의 주범이다.** Figma에서 콘텐츠를 찾는 1차 수단은
zoom-to-fit(Shift+1)인데, 멀리 떨어진 이상치 노드가 **하나만 있어도** fit이 그것까지 품느라 실제
콘텐츠가 점으로 찍힌다. 이상치는 대개 실수로 드래그해 날아간 노드나 옛 실험 잔해다.

[찾기 쉬움](README.md#찾기-쉬움-findability) 세 수단 중 zoom-to-fit을 담당한다. **효과가 가장 큰 룰**이다 —
나머지 둘([`outside_section`](outside-section.md) · [`default_name`](default-name.md))은 이미 기본 ON이므로,
못 찾겠는 페이지가 있으면 먼저 lint를 돌려 원인이 이상치인지 구조인지부터 확인한다.

## 파라미터

| 이름 | 기본값 | 설명 |
|---|---|---|
| `maxGap` | **3000px** | 이 거리 이내면 같은 덩어리로 묶는다 |

```jsonc
{ "builtins": { "content_spread": { "enabled": true, "maxGap": 3000 } } }
```

본진 판정 = 노드 수 최대 → 동수면 면적 합 최대.

## 오탐과 의도적 스코프 축소

- **숨김(`visible:false`) 노드는 제외.** 렌더되지 않으므로 fit 범위에 영향이 없다.
- **페이지 루트에서만 실행된다.** 서브트리는 좌표가 부모 로컬 기준이라 거리 판정이 무의미하다
  (`scope:"file"`은 항상 페이지 루트라 정상 동작).
- 의도적으로 멀리 두는 참고 자료(무드보드 등)가 있는 페이지에서는 위반이 난다 — `maxGap`을 키우거나
  노드별로 면제한다.

## 자동수정이 없는 이유

고치려면 최상위 노드를 통째로 옮겨야 하는데, 안전 fix(컨테이너 확장)의 범주가 아니고 **어디로 옮길지는
사람 판단**이다(check-first).

## 함께 켤 것

[`origin_anchor`](origin-anchor.md)와 **같이 켜야 의미가 있다.** 그쪽은 존재 검사라 원점 섹션 하나만
있으면 나머지가 흩어져도 통과하고, 흩어짐은 이 룰이 담당한다.

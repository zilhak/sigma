# `section_gap`

| | |
|---|---|
| 기본 | **ON** (opt-out) |
| 스코프 | 이웃 SECTION 간 |
| 추가 왕복 | 없음 |
| 자동수정 | 없음 |

## 무엇을 잡나

이웃한 섹션 사이 간격이 `gap`보다 좁은 것. 겹치지는 않지만 너무 붙어 있는 상태다.

## 왜 필요한가

**섹션 라벨은 섹션 경계 바깥 위쪽에 그려진다.** 두 섹션이 바짝 붙으면 아래 섹션의 라벨이 위 섹션의
몸통에 얹혀 읽히지 않는다. 겹침이 아니므로 [`section_overlap`](section-overlap.md)으로는 안 잡힌다.

## 파라미터

| 이름 | 기본값 | 설명 |
|---|---|---|
| `gap` | **80px** | 이웃 섹션 간 최소 간격. `0`이면 검사 비활성 |

```jsonc
{ "builtins": { "section_gap": { "gap": 60 } } }
```

## 오탐과 의도적 스코프 축소

- 라벨 높이는 줌 배율에 따라 화면상 크기가 달라지지만, 규칙은 문서 좌표 기준 고정값을 쓴다.
  팀 규약에 맞춰 `gap`을 조절하는 것을 전제로 한다.

## 면제하는 법

[`lint-ignore`](../suppress.md)로 노드별 면제. 간격 규약이 다른 파일이면 `gap`을 조절하거나 `0`으로 끈다.

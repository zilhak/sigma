# `frame_padding`

| | |
|---|---|
| 기본 | **ON** (opt-out) |
| 스코프 | 섹션 안 프레임 |
| 추가 왕복 | 없음 |
| 자동수정 | **있음** — 섹션 확장(grow container) |

## 무엇을 잡나

섹션 경계와 그 안 프레임 사이 여백이 `padding`보다 좁은 것.

## 왜 필요한가

프레임이 섹션 가장자리에 붙으면 섹션 경계선과 콘텐츠가 시각적으로 뭉치고, 섹션을 조금만 줄여도
바로 넘침([`child_overflow`](child-overflow.md))으로 넘어간다. 여백은 그 완충이다.

## 파라미터

| 이름 | 기본값 | 설명 |
|---|---|---|
| `padding` | **20px** | 섹션 경계와 내부 프레임 사이 최소 여백 |

## 자동수정

`sigma_lint({ apply: true })`로 **섹션을 키워** 여백을 확보한다. 프레임을 옮기지 않고 컨테이너를
키우는 방향만 자동수정 대상이다 — 프레임을 옮기면 다른 프레임과의 관계가 깨질 수 있어 사람 판단이
필요하기 때문이다.

dry-run(기본)에서는 `plannedFixOps`로 무엇을 얼마나 키울지만 반환한다.

## 오탐과 의도적 스코프 축소

- **[기획 레이어](../annotation-layer.md)는 면제된다**(`annotation_layer` 규칙을 켠 경우).
  섹션 전체를 덮는 것이 정상이므로 여백이 0이다.

## 면제하는 법

[`lint-ignore`](../suppress.md)로 노드별 면제. 여백 규약이 다르면 `padding`을 조절한다.

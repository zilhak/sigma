# `empty_container`

| | |
|---|---|
| 기본 | **ON** (opt-out) |
| 스코프 | FRAME / GROUP |
| 추가 왕복 | 없음 |
| 자동수정 | 없음 |

## 무엇을 잡나

FRAME 또는 GROUP인데 자식이 0개인 노드.

## 왜 필요한가

빈 컨테이너는 대개 **작업 중 남은 껍데기**다. 자식을 다른 데로 옮기고 컨테이너만 남았거나, 만들다 만
자리다. 화면에는 안 보이면서 레이아웃 계산과 레이어 패널만 차지한다.

## 파라미터

없음. `{ "enabled": false }`로 끄는 것만 가능하다.

## 오탐과 의도적 스코프 축소

- **fill로 내용을 그리는 노드는 제외**한다. 이미지 프레임처럼 자식 없이 IMAGE fill만으로 렌더되는
  경우가 정상 사용이라, 이걸 빈 껍데기로 잡으면 이미지를 넣을 때마다 위반이 난다.
- 배경·구분선 용도의 빈 프레임도 같은 이유로 fill이 있으면 통과한다.

## 면제하는 법

[`lint-ignore`](../suppress.md)로 노드별 면제 — 자리만 잡아 둔 플레이스홀더라면
`{"rules":["empty_container"],"reason":"stub"}`처럼 의도를 함께 적는다.

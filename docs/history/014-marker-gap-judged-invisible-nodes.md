# 014. 마커 규칙이 「보이는가」를 묻지 않아, 가려진 노드를 덮었다고 우겼다

> 관련 코드: `packages/shared/src/lint/annotation-marker.ts` (`PaintOrder`, `isHidden`),
> `packages/shared/src/lint/occlusion.ts` (`isOpaqueSolidFill` 공개)
> 2026-08-08

## 증상

모달(다이얼로그)이 떠 있는 상태 프레임에서, **모달 패널 위에 놓은 마커**가 이렇게 잡혔다:

```
annotation_marker_gap: 마커 "marker" (253:87746) 가 "table_cell" 을(를) 덮고 있다
```

그런데 그 `table_cell` 은 **불투명한 모달 패널(500×634 흰 바탕)에 완전히 가려 화면에 없다.**
마커는 패널 위에 있고, 패널 위의 요소(입력칸·체크박스·버튼)는 **하나도 덮지 않았다**(대상과 8px).

한 섹션에 3건. 모달·서랍·팝오버 상태 프레임은 롤아웃 규약상 거의 모든 페이지에 하나씩 있어서,
섹션마다 2~4건씩 사유 적은 `lint-ignore` 로 억제하고 있었다 — **억제가 쌓이는 것 자체가 신호**였다.

## 원인

규칙이 후보를 고를 때 **z 순서와 불투명 가림을 보지 않았다.** 마커 AABB 와 겹치는 모든 노드를
후보로 삼으니, 위에 무엇이 덮여 있든 아래 레이어 노드가 그대로 걸렸다.

2026-08-06 에 규칙을 좁히며 넣은 두 예외로도 못 걸렀다:
**배경판 제외**(마커 넓이 30배 초과)는 표 셀처럼 작은 노드에 안 걸리고,
**스치기 제외**(`minCoverRatio` 0.5)는 마커가 셀을 통째로 덮고 있으니 오히려 만족한다.
`dialog_overlay`(딤) 자체는 이미 제외됐지만, **딤 위에 얹힌 패널에 가려진 콘텐츠**는 대상이 아니었다.

## 무엇을 했나

후보에서 **완전히 가려진 노드**를 뺀다. 판정 세 조건 전부를 만족해야 가려진 것으로 본다:

1. 가림판이 **불투명**(노드 opacity 1 + 보이는 SOLID fill) — `fully_occluded_sibling` 의
   `isOpaqueSolidFill` 을 공개해 그대로 쓴다.
2. 가림판이 후보의 절대좌표 박스를 **완전히 포함**.
3. 가림판이 후보보다 **위(z)**.

| | `fully_occluded_sibling` | `annotation_marker_gap` |
|---|---|---|
| 좌표 | 부모 **로컬** (형제라 공통 원점) | **절대**(`absoluteX/Y`) |
| z 판정 | 형제 배열 인덱스 | **전역 페인트 순서** |

마커는 기획 레이어(섹션 최상위)에 있고 가려진 셀은 **다른 프레임 안**이라 공통 부모가 없다.
그래서 공유한 것은 **불투명 판정 하나**이고, 비교는 새로 썼다(`PaintOrder`) —
루트부터의 자식 인덱스 경로를 사전순 비교한다(Figma 는 깊이우선으로 그리고 `children` 뒤쪽이 위).

## 되돌리면 안 되는 이유

- **조상은 가림판에서 제외해야 한다.** 부모 프레임은 자식보다 **먼저** 그려지므로 자기 자식을
  가리지 못한다. 이 예외가 없으면 모달 패널이 **패널 위 버튼까지** 가린 것으로 판정해,
  후보가 0개가 되고 "가리킬 만한 요소가 없다" 라는 **반대 방향 오탐**으로 바뀐다
  (유닛테스트가 이 경우를 붙들고 있다).
- **가림 제외를 넣다 규칙이 통째로 무력해지는 것이 유일한 위험이다.** 그래서 positive control 을
  먼저 둔다 — 패널의 fill 을 빼면(=가리지 않으면) 종전대로 "덮고 있다" 가 나와야 하고,
  z 순서를 뒤집으면 다시 잡혀야 한다.
- **불투명 판정을 그라디언트·이미지까지 넓히지 말 것.** 완전 불투명을 증명할 수 없어
  누락을 택한 것이다(오탐 방지 우선). 여기서 넓히면 실제로 보이는 노드를 "가려졌다"고
  잘라내 규칙이 조용히 약해진다.
- 성능: 가림판도 후보와 같은 격자(`Grid`)에 담아 **마커 주변만** 훑고 후보별로 캐시한다.
  전수 비교로 되돌리면 큰 페이지에서 규칙 하나가 순회를 지배한다.

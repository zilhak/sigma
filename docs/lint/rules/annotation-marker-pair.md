# `annotation_marker_pair`

| | |
|---|---|
| 기본 | **OFF** (opt-in) |
| 스코프 | [기획 레이어](../annotation-layer.md) 단위 |
| 추가 왕복 | enrich (관계 + 하이퍼링크) |
| 자동수정 | 없음 |

## 무엇을 잡나

기획 레이어 안에서 **마커 ↔ 범례가 1:1이고 서로 왕복 하이퍼링크가 걸려 있는지**. 네 가지를 잡는다:

- **결번** — 설명 없는 마커
- **유령** — 가리키는 곳 없는 범례
- **중복 번호**
- **링크 누락**

## 왜 필요한가

번호는 **눈으로 하나씩 세어야만** 어긋난 것이 보인다. 마커를 빼고 재번호하다 보면 쉽게 어긋나는데,
검토자가 ①②③④⑥ 을 보고 ⑤가 빠진 걸 알아채기까지 시간이 걸린다.

링크는 더 나쁘다 — **화면에 아무 표시가 없어서** 빠뜨려도 티가 안 난다. 눌러 봐야만 안 걸린 걸 안다.

## 파라미터

| 이름 | 기본값 | 설명 |
|---|---|---|
| `markerAlias` | `marker` | 마커로 볼 스펙 alias |
| `legendAlias` | `legend` | 범례로 볼 스펙 alias |
| `requireHyperlink` | `true` | 왕복 링크를 요구할지 |
| `symbolPattern` | 원문자 숫자 한 글자 | 번호로 인정할 글자 패턴 |

> `symbolPattern` 기본값은 ㉑(U+3251)이 ①(U+2460)과 유니코드상 연속이 아니라 범위를 나눠 넣었다.

## 짝은 기획 레이어 단위로 맞춘다

**페이지 전체로 묶으면 안 된다.** 한 페이지에 섹션이 여럿이면 ① 번 마커도 여럿이라 전부 중복으로
잡힌다. 레이어 하나가 곧 "한 화면의 주석 세트"다.

## 판정은 이름이 아니다

스펙 alias + 인스턴스 안 번호 글자 + **실제 하이퍼링크 데이터**로 판정한다. 이름 규약을 만들지
않기 위함이다.

## 오탐과 의도적 스코프 축소

- 마커에 원문자가 아닌 **평문 숫자**를 쓴 경우도 번호로 인정한다.
- 링크를 일부러 안 거는 운영(범례만 나열)이라면 `requireHyperlink: false`로 끈다.

## 면제하는 법

[`lint-ignore`](../suppress.md)로 노드별 면제.

## 관련

링크 배선은 `sigma_set_hyperlink`. 마커와 대상의 **거리**는
[`annotation_marker_gap`](annotation-marker-gap.md)이 맡는다.

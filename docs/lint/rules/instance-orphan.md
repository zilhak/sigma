# `instance_orphan`

| | |
|---|---|
| 기본 | **ON** (opt-out) |
| 스코프 | 섹션·페이지 직속 |
| 추가 왕복 | 없음 |
| 자동수정 | 없음 (래퍼를 어디에 만들지는 사람 판단) |

## 무엇을 잡나

래퍼(프레임/컴포넌트/그룹) 없이 섹션이나 페이지 직속에 뜬 INSTANCE.

## 왜 필요한가

인스턴스는 그 자체로 화면의 한 단위가 아니라 **부품**이다. 래퍼 없이 섹션에 직접 놓이면 레이아웃
단위가 없어 이동·정렬이 불안정하고, 화면 구성이 인스턴스 나열로 평평해져 구조가 드러나지 않는다.

## 파라미터

없음. `{ "enabled": false }`로 끄는 것만 가능하다.

## 오탐과 의도적 스코프 축소

- **마스터 내부의 중첩 인스턴스는 정상**이라 대상이 아니다(정의의 사본).
- **`anno`/`wire` 프리셋 인스턴스는 예외**다. 기획 주석·와이어프레임 부품은 래퍼 없이 얹는 것이
  정상 사용이다.
- **[기획 레이어](../annotation-layer.md) 안은 면제된다**(`annotation_layer` 규칙을 켠 경우).
- **서브트리 검사에서 시작 노드가 FRAME/COMPONENT/GROUP/INSTANCE면** 그 직속 INSTANCE는 이미 래퍼 안에
  있는 것이므로 위반이 아니다.

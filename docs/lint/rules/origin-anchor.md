# `origin_anchor`

| | |
|---|---|
| 기본 | **OFF** (opt-in) |
| 스코프 | **페이지 루트 전용** — 서브트리 검사에선 실행 안 됨 |
| 추가 왕복 | 없음 |
| 자동수정 | 없음 |

## 무엇을 잡나

페이지에 최상위 SECTION이 하나라도 있으면, 그중 하나는 좌상단이 원점(0,0)에서 `tolerance` 이내여야
한다(음수는 절댓값). 위반은 **페이지당 최대 1건**이고, 주체 노드로 원점에서 가장 가까운 섹션을 실어 준다.

## 왜 필요한가 — 사람보다 도구를 위한 규약

Figma UI에는 "0,0으로 가기"가 없다. 원점에 콘텐츠가 있어도 사람이 거기로 점프할 수단이 없으므로,
이 룰은 **사람의 탐색을 돕는 규칙이 아니다.**

대신 좌표가 예측 가능해져 **에이전트의 배치·뷰포트 계산(`sigma_set_viewport`)이 안정된다.**
페이지마다 콘텐츠가 시작하는 좌표가 제각각이면 "왼쪽 위부터 훑기" 같은 단순한 전략이 통하지 않는다.

## 파라미터

| 이름 | 기본값 | 설명 |
|---|---|---|
| `tolerance` | **100px** | 원점에서 이 거리 이내에 시작하는 섹션이 하나는 있어야 함 |

```jsonc
{ "builtins": { "origin_anchor": { "enabled": true, "tolerance": 100 } } }
```

## 오탐과 의도적 스코프 축소

- **섹션이 없는 페이지는 검사 대상이 아니다** — 그건 [`outside_section`](outside-section.md)이 맡는다.
- **존재 검사라 느슨하다.** 원점 섹션 하나만 있으면 나머지가 아무리 흩어져도 통과한다.
- **페이지 루트에서만 실행된다.** 서브트리는 좌표가 부모 로컬 기준이라 원점 판정이 무의미하다.

## 함께 켤 것

[`content_spread`](content-spread.md)와 **같이 켜야 의미가 있다.** 위의 "존재 검사라 느슨하다"는 한계를
그쪽이 메운다.

## 자동수정이 없는 이유

섹션을 통째로 옮겨야 하고, 어느 섹션을 원점으로 삼을지는 사람 판단이다.

## 면제하는 법

[`lint-ignore`](../suppress.md)로 면제하거나, 좌표 규약이 없는 페이지면 켜지 않는다.
